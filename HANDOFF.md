## Project Overview
Цель: пользователь вводит слово и IPA-транскрипцию; система ищет
релевантные фрагменты PDF и формирует ответ с источниками.
Пользователь: только автор проекта.
Ключевая ценность: авторское объяснение механики произношения
(дыхание, положение языка, губ) с опорой на страницы источника.
Заметка: проект выполнен как ДЗ урока PEr08, сейчас используется
как материал для практики хендоффа в PEd05.

## Prompt Engineering Guide
Промпт: строгий RAG-промпт без права на выдумывание фактов, полный
текст — SYSTEM_PROMPT в rag_pipeline.py (см. ссылку на файл ниже).
Параметры: model="gpt-4o-mini", temperature=0, max_tokens — не задан (default).
Ограничения:
1. Отказ по невалидным фонемам — вне набора /p/ /f/ /v/ /z/ или при
   недостатке контекста выдаётся только шаблонный отказ.
2. Не приводит к единой трактовке — при противоречащих формулировках
   в источнике модель показывает обе версии, не выбирая одну.

## Метрики и риски
### Метрики успеха (целевые показатели, пока не измерялись)
- Доля корректных ответов по 4 поддерживаемым фонемам: 82%
- Cache hit rate: 90%
- Экономия времени по сравнению с ручным поиском в учебнике: 70%

### Риски / ограничения
- Узкий набор поддерживаемых фонем (/p/ /f/ /v/ /z/)
- Нет автоматической оценки качества (RAGAS/precision/recall)
- OCR может искажать IPA в тексте PDF-учебника
