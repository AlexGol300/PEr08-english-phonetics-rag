## Project Overview
Цель: пользователь вводит слово и IPA-транскрипцию; система ищет 
релевантные фрагменты PDF и формирует ответ с источниками.
Пользователь: только автор проекта.
Ключевая ценность: авторское объяснение механики произношения 
(дыхание, положение языка, губ) с опорой на страницы источника.
Заметка: проект выполнен как ДЗ урока PEr08, сейчас используется 
как материал для практики хендоффа в PEd05.

## Prompt Engineering Guide
Промпт: см. SYSTEM_PROMPT в rag_pipeline.py (вставь текст дословно, 
он у тебя уже выписан выше).
Параметры: model="gpt-4o-mini", temperature=0, max_tokens — не задан (default).
Ограничения:
1. Отказ по невалидным фонемам — вне MVP-набора /p/ /f/ /v/ /z/ или 
   при недостатке контекста выдаётся только шаблонный отказ.
2. Не приводит к единой трактовке — при противоречащих формулировках 
   в источнике модель показывает обе версии, не выбирая одну.

Валидированы только фонемы /p/, /f/, /v/, /z/.

В MVP не входят:

VLM и описание изображений;
мультимодальный поиск;
web- или Telegram-интерфейс;
Docker;
несколько PDF или несколько LLM;
оценка качества RAGAS.
OCR учебника может искажать IPA в тексте PDF; поэтому retrieval ограничен валидированными страницами для поддерживаемых фонем.
